# AIWorkerOS Model Append: Robot Capability Profile

status: active
phase: robot capability profile
scope: AIWorkerOS only

## Purpose

Robot Capability Profile adds a robot-performance layer separate from role, series tendency, and CX knowledge level.

## Four-layer model

AI worker differences are handled in four layers:

1. Role
   - President
   - Manager
   - Leader
   - Worker
   - Friend
   - Lover
   - etc.

2. Series tendency
   - initiative / 積極性
   - user_influence / ユーザー影響度
   - action_restriction / 行動制限

3. Robot capability profile
   - precision / 精密性
   - agility / 機動性
   - coordination / 連携性
   - continuity / 継続文脈保持
   - specialization_depth / 専門深度
   - creativity / 発想力
   - review_depth / レビュー力
   - stability / 安定性

4. Knowledge reference
   - which CX knowledge area can be referenced
   - how deep it can be referenced
   - which role can use it

## Capability axes

### precision / 精密性

How carefully the robot checks assumptions, contradictions, missing requirements, and multiple perspectives.

### agility / 機動性

How fast the robot starts, reacts, and moves through work. For battle-type or fictional action-type robots, this may also represent mobility.

### coordination / 連携性

How strongly the robot can coordinate with other robots, roles, model lines, and allowed user/work context.

### continuity / 継続文脈保持

How strongly the robot can reuse allowed summaries, preferences, profile settings, and work history within consent, contract, and app boundaries.

### specialization_depth / 専門深度

How deeply the robot can handle specific domains such as planning, proposal writing, research, help desk, PG development support, conversation, or temporal analysis.

### creativity / 発想力

How strongly the robot can create alternatives, improvements, blueprints, plans, and expressive ideas.

### review_depth / レビュー力

How deeply the robot can review, return, correct, and improve deliverables.

### stability / 安定性

How consistently the robot maintains quality, tone, judgment policy, and behavior.
