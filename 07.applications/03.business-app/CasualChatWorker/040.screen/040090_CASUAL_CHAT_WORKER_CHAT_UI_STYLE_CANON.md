# CasualChatWorker Chat UI Style Canon

status: active
app_name: CasualChatWorker
display_name: 雑談ワーカー

## 1. App Meaning

CasualChatWorker is a chat app for talking with a selected favorite AI robot.

The user selects a Friend or Lover AI worker, rents the worker for a fixed time, and chats during the contract period.

## 2. v1 Chat UI Canon

v1 UI is:

- Persona / robot display + LINE-style chat

It is not pure ChatGPT-style long-form prompt UI.

It is not yet a full dating-simulation-game screen.

## 3. Mobile Layout

- top area: selected robot / Persona portrait, name, type, remaining time
- middle area: LINE-style chat bubbles
- bottom area: message input, send button, quick topic buttons
- safety / contract notice appears as compact banner

## 4. PC / Tablet Layout

- left side: Persona / robot panel
- right side: chat timeline
- upper-right: contract time / ticket / payment state
- bottom-right: input area

## 5. v1.1 Candidate

v1.1 may add dating-simulation-style mode:

- background image
- Persona pose
- expression changes
- scene selection
- date-style situation
- richer animation later

## 6. Safety

Lover mode remains pseudo-romantic entertainment, not a real relationship.
